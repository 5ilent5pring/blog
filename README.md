# 5ilent5pring blog

Static blog for `5ilent5pring.org`, generated by `go run main.go`.

## Structure

- `index.html` and `js/blog.js` are the main personal/professional site.
- `content/` contains source markdown posts.
- `posts/` contains generated HTML for existing post URLs.
- `posts.json` is the main-site post database.
- `geocti-site/` is a standalone static root for `geocti.5ilent5pring.org`.

The main site keeps human-authored writing in the primary feed. geoCTI remains generated from the same markdown sources, but the main site links those briefs to the subdomain and shows only a small preview.

## Build

```bash
go run main.go
```

The build updates:

- `posts.json`
- `posts/`
- `geocti-site/posts.json`
- `geocti-site/posts/`

## Deploy Shape

Recommended setup:

1. Keep `5ilent5pring.org` pointed at the current main blog deployment.
2. Create a second deployment for `geocti-site/`.
3. Attach `geocti.5ilent5pring.org` to that second deployment.

Cloudflare is already authoritative for the domain, so Squarespace should not need DNS record edits unless nameservers were changed back there. Manage the subdomain in Cloudflare.

For Cloudflare Pages, create or connect a Pages project to the same GitHub repo and set the build output/root to `geocti-site/`, then add `geocti.5ilent5pring.org` under the Pages project's custom domains. Cloudflare will create the needed DNS record for zones it manages.

For GitHub Pages, publish `geocti-site/` as the root of its own Pages site or repo. The included `geocti-site/CNAME` contains `geocti.5ilent5pring.org`.
